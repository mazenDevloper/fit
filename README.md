# Madar for iPhone

Native shell for Madar (https://mazendevloper.github.io/fit/): ARKit 6DoF + lens-matched Metal passthrough,
Apple Vision hands, room planes, Arabic speech, controller haptics, spatial video → SBS, bridge in every frame.
Built by `.github/workflows/ios.yml` → release `ios-latest` (Madar.ipa, unsigned; install with iloader).
